# 项目约定

## Git 版本管理

- 每次完成用户要求的一组代码、样式、资源、配置或文档改动后，都要创建 Git 提交；同一需求的相关改动归入一个提交。
- 提交前检查差异并执行与改动相关的验证。应用代码或依赖变更运行 `npm run build`；纯文档或 Git 配置变更检查内容与格式即可。
- 只暂存本次任务相关文件，保留用户已有改动，提交信息简洁说明改动目的。
- 完成后在回复中给出提交短哈希和验证结果。
- 不自动推送远程仓库、改写历史或撤销已有提交，除非用户明确要求。

## 验收与资源

- 用户自行验收页面，不主动打开浏览器或执行浏览器自动化。
- 图标使用 Figma 导出的本地静态资源，不自行绘制替代图标。
